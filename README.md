# Stella Sora — Việt Hóa (AmeeVH)

Bản dịch tiếng Việt thử nghiệm cho Stella Sora (EN) đa nền tảng.

### 📥 Tải Về Cài Đặt
- **PC Windows**: Tải `StellaSora_Launcher_PC.zip` trong [Releases](../../releases), giải nén và chạy `Start_Launcher.bat` để cài đặt 1-chạm hoặc khôi phục gốc.
- **Android**: Tải `StellaSora_VietHoa.apk` trong [Releases](../../releases) để bật overlay thông báo và nạp qua Local ADB.

### ✨ Tính Năng
- Tự động cập nhật từ GitHub.
- Bảng tin thông báo in-game.
- 1-chạm sao chép log lỗi gửi Dev.
