# Stella Sora — Việt Hóa (AmeeVH)

Bản dịch tiếng Việt hoàn chỉnh cho **Stella Sora (EN)** đa nền tảng: Steam PC, Yostar Standalone PC và Android.

### 📥 Tải Về Cài Đặt (Phiên Bản v0.8.0 Mới Nhất)
- **PC Windows (Steam & Yostar)**: Tải file thực thi StellaSora_Launcher.exe trong [Releases](../../releases) để cài đặt 1-chạm hoặc khôi phục gốc (chạy trực tiếp không cần cài Python).
- **Android**: Tải StellaSora_VietHoa.apk trong [Releases](../../releases) để bật overlay thông báo và nạp qua Local ADB.
- **Trực tiếp Game Data**: Tải data_patched_vi.arcx trong [Releases](../../releases) và chép vào Persistent_Store/Tables/data.arcx.
