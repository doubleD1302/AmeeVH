# Stella Sora Việt Hóa

AmeeVH là dự án Việt hóa **Stella Sora (EN)**, giúp người chơi trải nghiệm giao diện và nội dung game bằng tiếng Việt trên Windows và Android.

## Thông báo

- Bản phát hành hiện tại: **1.2.0**, hỗ trợ bản cập nhật game 2.0.1.
- Bản **1.2.1** đang được thử nghiệm và chưa phải bản phát hành chính thức.
- Xem thông tin cập nhật và tải launcher cho Windows hoặc Android tại [GitHub Releases](https://github.com/doubleD1302/AmeeVH/releases/latest).

Cảm ơn bạn đã đồng hành cùng dự án!
