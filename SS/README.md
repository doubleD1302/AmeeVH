# Hướng dẫn sử dụng

Nhờ AI quét qua thì chắc nó sẽ tóm tắt cho biết cần phải làm gì thôi.

Merge -> Update glossary -> Translate -> Review, rồi lại vòng lặp mới, đại khái workflow 
là thế. Muốn chạy thì chỉ cần yêu cầu các folder muốn workflow nó dịch là được.

Thường thì mỗi vòng loop thì chỉ nên merge khoảng 4 folder một thôi, sợ dài quá nó quên
context.  

Chạy cái này cũng tốn kha khá quota đấy, nên có thể cứ xong 1 đến 2 chapter thì update-sheet một lần.

Chỉnh lại web nhé, có hướng dẫn trong readme_sheet_database đấy. 

Có thể chịnh lại model và reasoning effort của sub-agent.

Khi nào ngừng AI local chuẩn bị ngừng làm việc thì push và commit những thay đổi trong cả folder này lên lại Github nhé.

Muốn tạo skill gì mới thì hãy trao đổi lại
