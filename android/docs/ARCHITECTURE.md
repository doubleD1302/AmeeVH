# Native architecture and channel contracts

MainActivity serves only https://stella.local.invalid/ from bundled assets and implements the root UI action contract. LauncherService owns one foreground worker/wakelock, operation state and journals. AdbBrokerService is non-exported, sameUID and process:adb. Both socket creation and pair/connect/read/close have absolute broker-main deadlines; timeout selfkill checks exact process suffix. Cancellation also checks PID+UID+suffix and never blocks on manager.disconnect. AdbClient has binding generations to ignore stale service callbacks.

Pair notification: highimportance channel, RemoteInput mutablePendingIntent only for reply, explicit non-exported PairingReceiver, unpredictable URI nonce and current-session validation. Codes stay transient. mDNS _adb-tls-pairing._tcp then _adb-tls-connect._tcp accepts loopback/own interfaces only. Android13notification permission is requested by visibleActivity; denied/mDNSfailure has manual host/ports/code fallback. A successful id response is required after connect.

Game identity: official global EN listing https://play.google.com/store/apps/details?id=com.YoStarEN.StellaSora . Actual pm path, current Androiduser, canonical external game filesroot, stable same-device identity and actual GAME_VER/RES_VER headers are read. Unknown/ambiguous headers stop install; no Windows version/path assumption.

Android translation metadata release assets: android_patch_manifest.json or stella_android_manifest.json. Raw asset size/SHA from GitHub bind JSON before parsing. Required fields: platform=android, game_package=com.YoStarEN.StellaSora, client_game_version,resource_version,version,files(array or pathmap). Each file requires path,url(or source_url),size,sha256. Bundle also requires asset_platform=android. Allowed: Persistent_Store/Tables/data.arcx, Scripts/lua.arcx, Videos/*.srt, AssetBundles/*.unity3d. No undeclared data/lua added from release asset names. Compatibility comes only from explicit Android metadata and actual device headers.

Native transaction: all downloads hash before gamewrites; same-device/root/package version/gameclosed/storage preflight; snapshot/backup+hash; PREPARING thenAPPLYINGjournal before writes; perfile oldimageguard, siblingtemp hash, atomicrename and readback; receipt afterallfiles. Journal/receipts are own privatefiles; backup/staging in own externalfiles readable by shell. Restore requires correct binding, allcurrentpostimages, allbackuphashes, gameclosed and unchanged versions. Interrupted recovery permits only before/after states and never overwrites thirdparty changes. Operation-owned temporary paths are tracked before creation and safely regenerated/cleaned during recovery.

APK metadata assets: android_localadb_launcher.json or stella_android_localadb_channel.json. Required platform=android,variant=localadb,application_id=com.stellasora.viethoa.localadb,version_code,version_name,apk_url,size,sha256,signing_cert_sha256. Candidate archives independently checked by PackageManager: appID,variant,newercode,exact current signer set and metadata signer. Android user grants source permission and confirms systeminstaller via the one-file read-only UpdateProvider. OverlayAPK/PCEXE never accepted.

No runtime/device tests were executed. Native/transport/OEM/versionheader/UI/transaction/update behaviors require the user's device evaluation.
