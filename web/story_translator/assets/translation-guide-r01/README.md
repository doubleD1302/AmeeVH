# TramVH — icon hướng dẫn dịch thuật

8 icon SVG vẽ riêng theo nét, màu và kích thước của bộ Soft Sky đang dùng trên TramVH. Mỗi icon có bản sáng/tối: guide, workflow, style, pronouns, tokens, checklist, search và close. Không thay logo, favicon hoặc icon của tính năng khác.

Trong giao diện, icon dùng ở nút mở, mục lục, tiêu đề từng phần, tìm kiếm và đóng sổ tay. Kích thước hiển thị: 24 px ở mục lục, 32 px ở tiêu đề, vùng chạm mobile tối thiểu 44 px. Chữ nằm trong HTML để hỗ trợ trình đọc màn hình và thay đổi nội dung dễ dàng.

Nguồn vẽ: `tools/build_tramvh_guide_vectors_20261031_r01.py`. `manifest.json` ghi SHA256 từng file. Đây là vector gốc của dự án; không dùng ảnh tạo sinh trong giao diện hướng dẫn cuối cùng.
